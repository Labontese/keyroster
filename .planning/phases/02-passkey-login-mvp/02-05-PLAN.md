**Backend `software`** (internal/keystore/software, signer-safe; already covered by the `**/internal/keystore/**` depguard rule).
- `init` registers `software`. The factory runs `keystore.CheckOptions(opts, "passphrase-file")`.
- Passphrase source, in order:
  1. opts["passphrase-file"];
  2. else `$CREDENTIALS_DIRECTORY/keyroster-software-passphrase` when CREDENTIALS_DIRECTORY is set;
  3. else an error naming both ways.

  For an operator file, refuse a mode with group or other bits. Trim exactly one trailing newline, require at least 20 runes, and clear the byte slice after use.
- `Provision(roles)`: refuse if `{state-dir}/software` already holds any `.age` file. Generate one Ed25519 key per role with crypto/rand, marshal it as an OpenSSH private key, and encrypt it to an armored age file with one scrypt recipient at age's default work factor. Write with O_EXCL, mode 0600, in a 0700 directory, then fsync. Return the public keys.
- `Key(role, fingerprint)`: decrypt `{role}.age` with `age.NewScryptIdentity` through `armor.NewReader` and `io.LimitReader`, parse the key and require the fingerprint to match. Return a CAKey with `Custody()` = keystore.CustodySoftware and `Algorithm()` = `ssh-ed25519`. A wrong passphrase returns an error that does not echo the passphrase.
- Register it with a blank import in cmd/keyroster-signer/backends_linux.go.

**Status (D-18).**

  - Encoding: u8 count (5 roles), u16 strings, u24 documents, strict decode.
