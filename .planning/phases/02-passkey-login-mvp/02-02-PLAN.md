**internal/winagent (all files `//go:build windows`).**
- `PipePath() (string, error)` returns `\\.\pipe\keyroster-agent-` plus the current user's SID string. `SDDL(sid string) string` returns `D:P(D;;GA;;;NU)(A;;GA;;;<sid>)`.
- `Serve(ctx context.Context, path string, opts Options) error` uses `winio.ListenPipe(path, &winio.PipeConfig{SecurityDescriptor: SDDL(sid)})`. The first-instance creation refuses an existing pipe, so a second agent or a squatter is refused, and the error says so. It serves every connection with `agent.ServeAgent(keyring, conn)` on one `agent.NewKeyring()`.
  - Lifecycle: every `opts.Poll` (default 5 s) call `keyring.List()`, which expires lifetime-constrained keys. Exit with nil once a key was ever added and the list is now empty, or when no key was added within `opts.IdleExit` (default 5 min).
  - The exit decision is atomic with connection handling (addresses review finding 02-02-F5). One mutex guards an `active` connection counter and an `exiting` flag. The accept loop takes the mutex for every accepted connection: if `exiting` is set it closes the connection at once, otherwise it increments `active` before serving and decrements it when the connection ends. The poll takes the same mutex and decides to exit only when `active == 0` and the exit condition above holds; it then sets `exiting`, closes the listener, and Serve returns after the serving goroutines have ended. So Serve never returns while a client holds an open connection, and a key added on such a connection is never lost to an exit.
  - Serve never re-listens or "resumes" after closing its listener: recreating the pipe would reopen the window in which another process creates it first (T-02-07). A client that loses the race sees its connection closed, and Ensure retries once (below).
  - Options exists so tests can shorten the timings. There is no environment or flag override.
- owner_windows.go `VerifyServerOwner(conn net.Conn) error`:
  1. take the pipe handle from the connection's `Fd()`;
  2. get the server PID with GetNamedPipeServerProcessId (golang.org/x/sys/windows if it wraps it, else a `windows.NewLazySystemDLL("kernel32.dll")` call);
  3. OpenProcess with PROCESS_QUERY_LIMITED_INFORMATION, OpenProcessToken, GetTokenUser;
  4. call the unexported `checkOwner(server, want *windows.SID) error` with the token SID and the current user's SID. checkOwner returns nil only when `server.Equals(want)`, otherwise an error naming both SIDs in string form. The comparison lives only in checkOwner, so a test can pass any SID (addresses review finding 02-02-F1).

  An access-denied result (windows.ERROR_ACCESS_DENIED) from OpenProcess or OpenProcessToken returns `ErrOwnerUnverifiable`, wrapped with this guidance: the agent pipe is served by a process this shell cannot inspect, most likely a keyroster agent started from an elevated ("Run as administrator") shell; stop that process, or wait until it exits on its own (when its last key expires, or 5 minutes after start without a key), then run the command again from a normal shell. Every other error is returned as is. Both cases fail closed (addresses review finding 02-02-F8).
- ensure_windows.go `Ensure(ctx context.Context, exe string) (net.Conn, error)` calls the unexported `ensure(ctx, path string, start func() error, verify func(net.Conn) error)` with PipePath(), a start function that launches `exe agent`, and VerifyServerOwner. The parameters exist only so tests can use a test pipe, start an in-process Serve and make the verifier reject; there is no environment, flag or build-tag override. Ensure itself gains no exported test hook: it always dials PipePath() and starts `exe agent`. A caller outside this package that needs a test pipe wraps its Ensure call in its own package-level function variable, as cmd/keyroster already does with `dialAgent`; 02-12 does that with `connectLoginAgent` in cmd/keyroster/loginagent_windows.go, and its tests point that variable at an in-process Serve on a test pipe, checked with the exported VerifyServerOwner. Tests of the Ensure leg itself (dial, start, verify, List) stay in this package. ensure:
  1. dial path. An access-denied dial (an elevated agent's pipe refusing a normal shell) returns ErrOwnerUnverifiable with the same guidance;
  2. on file-not-found, call start (in production: `exe agent` with `SysProcAttr{CreationFlags: windows.CREATE_NEW_PROCESS_GROUP | windows.DETACHED_PROCESS, HideWindow: true}`) and poll the pipe for up to 5 s;
  3. call the verifier on the connection. On any verifier error, close the connection and return nil plus that error (fail closed: no key is ever sent to an unverified pipe, and there is no fallback to another pipe);
  4. confirm the connection is being served with one agent `List` request (`agent.NewClient(conn).List()`). Once it succeeds, the agent counts the connection as active and cannot exit while it is open. If List fails because the agent was shutting down (connection closed or EOF), close the connection and run steps 1-4 once more, which starts a fresh agent; a second failure is returned as an error.
