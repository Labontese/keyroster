<objective>
An offline break-glass CA, distributed by the agent, grants login to the dedicated emergency account and nothing else, and keeps working when the server is down or the main KRL or CA file is broken (BREAK-01, D-13).

The homelab drill is in 03-16; logging of break-glass use in reconciliation is BREAK-02 (Phase 5).
</objective>
