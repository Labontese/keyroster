## Pattern Assignments

### `internal/krl/*` (codec, transform)

**Analog:** `internal/tlog/leaf.go` — strict cryptobyte encode/decode with size limits and a sentinel error.

Size-limit constants (lines 79-91) and encode (lines 111-125):
```go
func MarshalLeaf(l Leaf) ([]byte, error) {
	if !l.Kind.valid() {
		return nil, fmt.Errorf("%w: unknown kind %d", ErrMalformedLeaf, l.Kind)
	}
	if len(l.Body) > maxBody {
		return nil, fmt.Errorf("%w: body too large", ErrMalformedLeaf)
	}
	var b cryptobyte.Builder
	b.AddUint8LengthPrefixed(func(b *cryptobyte.Builder) { b.AddBytes([]byte(LeafDomain)) })
	b.AddUint64(l.Index)
	...
	return b.Bytes()
}
```
Copy: exported `Max*` limits, `ErrMalformed*` sentinel wrapped with `%w`, `DecodeX` that is strict (rejects trailing bytes). Serial 0 never matches (krl.c:1199); `internal/serial` never yields 0.

**Oracle test analog:** `internal/sshsig/oracle_test.go` lines 19-48 — run `ssh-keygen` in `t.TempDir()`, and include a negative control so a pass is meaningful:
```go
// Control: the oracle refuses the same signature under another
// namespace, so the pass above is meaningful.
if out, err := keygenVerify(keygen, allowed, "keyroster/other/v1", sigFile, msg); err == nil {
	t.Fatalf(...)
}
```
For KRL: `ssh-keygen -Q -f revoked.krl cert.pub` must report revoked for listed serials AND not revoked for an unlisted one. Fuzz: add the target to `scripts/fuzz.sh`, seed corpus in `testdata/fuzz/`.
