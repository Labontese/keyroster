<objective>
Bind every admin-signed directory to one installation (D-04, the format change pulled in from the 2026-10-16 todo) and give the directory the two kinds of entries Phase 3 needs: hosts (one host group each, admin-typed certificate principals, host keys) and machines (key, roles, TTL), plus the root-signed policy switch that later enables proof-of-possession issuance for them.

Purpose: AUTHZ-02's "signed host policy" is the host entry plus its host group, signed by the admin quorum; agents (03-07) and the signer (03-09, 03-11) read nothing else. AGENT-03's installation binding becomes enforceable. AUTH-06's machine identities get their signed definition.

Output: directory format additions, signer and audit checks, policy PoP field, host and machine CLI commands, an e2e test, golden vectors, runbook sections, the closed 2026-10-16 todo, and a PR.
</objective>

Validate adds:
