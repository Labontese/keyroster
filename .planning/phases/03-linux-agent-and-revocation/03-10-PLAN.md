<objective>
Complete the agent's self-test (D-06): after every change, prove with real sshd that a probe certificate is accepted and a revoked one is refused, so a broken CA file, principals file or KRL is caught and rolled back before anyone is locked out, and KRL enforcement itself is proven on every host.

Purpose: AGENT-04's "self-tests and rolls back on failure" at full depth.

Output: the probe issuance path (wire, signer, leaf kind 12, audit), probe account checks, the PK_OK self-test, distro-matrix cases for UsePAM and penalties, the probe-account runbook, and a PR.

**PK_OK without signing (implementation note).** golang.org/x/crypto/ssh's client first sends each public key as a query without a signature and signs only after the server answers PK_OK. The agent's probe signer records "PK_OK received" when asked to sign and returns an error instead of a signature, so no authentication completes and no session opens.
</objective>
