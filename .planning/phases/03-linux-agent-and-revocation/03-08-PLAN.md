<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent → server (heartbeat) | The server records the agent's own word; a compromised host can fake its heartbeat |
| server → admin (status) | Convergence is the server's word; a compromised server can lie |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-50 | Tampering | a server that freezes the KRL (serves the last valid one forever) | medium | mitigate | Hourly re-publish (03-03); agents alert at 24 h and flag krl_stale; the server flags silence; never a lockout (D-10) |
| T-03-51 | Repudiation | a server lying about convergence before a CA switch | medium | accept | Availability only: the drain end date in the bundle (03-12) and the agent's own clock decide when the old CA goes; `keyroster-agent check` on a host is the proof; status output says so |
| T-03-52 | Spoofing | replayed or reordered heartbeats hiding a failed apply | low | mitigate | Monotonic seq; lower or equal refused |
| T-03-53 | Denial of service | heartbeat floods | low | mitigate | Agent limiter class, 64 KiB cap, one row per agent |
| T-03-54 | Elevation of privilege | the units granting more than each process needs | high | mitigate | Fetcher unprivileged with no capabilities; applier IPAddressDeny=any with localhost only and ReadWritePaths limited to its three paths; systemd-analyze security gated in CI |
| T-03-55 | Spoofing | identity rotation by a party without the old key | medium | mitigate | Rotation requires mTLS with the current identity and the old key's signature over the new SPKI |
| T-03-SC | Tampering | dependencies | low | accept | No module change |
</threat_model>
