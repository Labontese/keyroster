| Boundary | Description |
|----------|-------------|
| Signer → TPM resource manager | Key use requires the TPM device and each key's auth value |
| Other local users → TPM | Members of group tss can talk to the TPM |
| Hypervisor host → vTPM state | The vTPM's state is a file outside the VM |
| Upstream module → CA key path | go-tpm-keyfiles is untagged code in the signing path |
