## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI → OpenSSH tarballs | Downloaded source compiled and executed on runners (verification lives in `scripts/build-openssh.sh`, T-01-16) |
| PR runs → CI cache | A PR's workflow run can write caches that later runs might restore |
| Ruleset change → main | New required checks gate every later merge |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-69 | Tampering | actions/cache of the OpenSSH prefix | medium | mitigate | Cache key = OpenSSH version + `hashFiles('scripts/build-openssh.sh')`; GitHub scopes caches written by PR runs to that PR's ref, so a PR cannot replace main's cache; the stamp file records version and tarball SHA-256 and the script rebuilds on a mismatch |
| T-01-70 | Denial of service | required-check rollout | medium | mitigate | The three contexts are added to main-integrity only after they reported success on this PR (Pitfall 10); the rules API confirms them on main |

| T-01-SC | Tampering | GitHub Actions (checkout, setup-go, cache, upload-artifact) | high | mitigate | All actions GitHub-owned and SHA-pinned from the research table; no Go modules or package-manager installs added in this plan |
</threat_model>
