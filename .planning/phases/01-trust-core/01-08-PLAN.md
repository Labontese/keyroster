## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keyroster-signer → ssh-agent | The signer asks the agent to sign; the agent holds token sessions |
| ssh-agent → ssh-pkcs11-helper → vendor module | Vendor C code isolated in a helper process |
| CI logs → public | Workflow logs on a public repo are world-readable |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-45 | Elevation of privilege | signer's ssh-agent | high | mitigate | Dedicated socket owned by the signer user, `-P` provider allowlist, never forwarded; guide recommends OpenSSH 10.5+ (forwarded locked-agent fix) |
| T-01-46 | Information disclosure | PKCS#11 PIN | medium | mitigate | Random PIN in a 0600 file, delivered via SSH_ASKPASS; test asserts the PIN is absent from captured output |
| T-01-47 | Spoofing | agent key selection | medium | mitigate | Keys chosen by pinned fingerprint per role; custody declared and recorded in the bundle; CA and root tokens in separate agents |
| T-01-SC | Tampering | apt packages softhsm2, opensc | medium | mitigate | Ubuntu archive packages installed only in CI/WSL test environments; no Go modules added |
</threat_model>
