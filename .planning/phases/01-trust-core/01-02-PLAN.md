## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local process → signer Unix socket | Any local process may try to connect; only allowlisted peers may send a frame |
| Request bytes → decoder | Frames are attacker-controlled until strictly parsed |
| Signer → ssh-agent | The agent may hold keys other than the pinned CA key, including certificates |
| CI → OpenSSH tarballs | Downloaded source compiled and executed in CI |
