## Budget Exception (recorded in revision iteration 2)

This plan lists 32 files, above the checker's per-plan file threshold of 15. The exception is deliberate:
- **What was split out.** The refusal and edge-case suite that made the plan 41 files (nine test files across seven packages, four fuzz targets, a TDD task) moved to plan 01-16, which runs next (wave 3) and gates plan 01-04. That task was about 30% of this plan's context; the projection drops from 88k to 62k tokens, inside the 100k smart zone.
- **Why the rest stays together.** Task 1 is the Walking Skeleton tracer. Its contract is to prove CLI → Unix socket → signer → certificate → real sshd accepts, and every listed package is one layer of that single path: wire, cert, serial, keystore and agent, state DB, signer, client, two binaries, the e2e harness and the OpenSSH build. Removing any layer either breaks the end-to-end proof or leaves a stub that needs an architectural change later (for example an in-memory serial that 01-05's single-transaction audit append cannot build on).
- **Why the count overstates the cost.** This is a greenfield repository, so every file is new and small. Seven entries are near-boilerplate: `go.mod`, `go.sum`, the migration SQL, the `!linux` stubs `main_other.go` and `peercred_other.go`, `backends_linux.go` (one blank import) and `registry.go`. Task 2 adds only one guard test and one lint stanza, and Task 3 is the merge gate, which carries no implementation context.
- **Why the guard stays here.** The `SignCert` guard test and the `signer-no-network` depguard rule are the two invariants that later code is most likely to erode. Keeping them in this plan means `main` never holds the signer without them, at a cost of two small files.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local process → signer Unix socket | Any local process may try to connect; only allowlisted peers may send a frame |

| Signer → ssh-agent | The agent may hold keys other than the pinned CA key, including certificates |
| CI → OpenSSH tarballs | Downloaded source compiled and executed in CI |
