# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub private vulnerability reporting:

https://github.com/Labontese/keyroster/security/advisories/new

Do not report vulnerabilities in public issues, pull requests or discussions.

Include what you found, how to reproduce it, and the impact you expect. You will get an acknowledgement, and the fix will be coordinated with you before anything is disclosed.

## Supported versions

keyroster is pre-alpha. There are no releases yet and therefore no supported versions. Fixes land on the `main` branch.
